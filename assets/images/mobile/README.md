Carrusel de Imágenes - Versión Mobile
    -Este carrusel muestra imágenes cuadradas optimizadas para pantallas móviles. Cambia automáticamente -cada 5 segundos y permite navegación manual tocando los lados de la imagen.

Dimensiones de imagenes:
    -810 px × 810 px (formato cuadrado 1:1)

⚙️ Características:
    -Adaptado para pantallas ≤768 px.
    -Navegación táctil con zonas clicables a la izquierda y derecha.
    -Transición suave con efecto fade.
    -Imágenes precargadas para una experiencia fluida.
