# 🌊 Don Piero Piscigranja - V1

Este es el proyecto web oficial de **Don Piero Piscigranja**, una propuesta digital inicial (versión 1) que busca mostrar información de la empresa, sus servicios, y brindar interacción directa con clientes mediante formularios y WhatsApp.

---

## 📌 Descripción del Proyecto
La página web fue desarrollada como **primera versión (V1)** para ofrecer a los clientes una experiencia sencilla y directa.  
Incluye:

- Secciones informativas sobre **Don Piero Piscigranja**.
- Menú y opciones de platos disponibles.
- Sistema de reservas y contacto por **WhatsApp**.
- Scripts personalizados para automatizar procesos y mejorar la experiencia del usuario.
- Integración de **Google Apps Script** para conexión con Google Sheets (gestión de datos de clientes y publicidad).

---

## ⚙️ Tecnologías Utilizadas
- **HTML5** → Estructura del sitio.  
- **CSS3** → Estilos y diseño visual.  
- **JavaScript (JS)** → Funcionalidad interactiva y dinámica.  
  - Envío de datos a **WhatsApp**.  
  - Automatización con **Google Apps Script**.  
  - Manejo de múltiples scripts (9 JS en total).  
- **Google Apps Script** → Conexión con Google Sheets para almacenamiento de datos.
