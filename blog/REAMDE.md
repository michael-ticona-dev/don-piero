📄 README – Blog de Don Piero

¿Qué es esto?
-------------
Este sistema permite mostrar publicaciones semanales en la web de Don Piero de forma fácil.
Solo necesitas subir un archivo .txt llamado `post.txt` y el contenido se mostrará automáticamente en la sección “Blog”.

✅ ¿Cómo actualizo el blog?
---------------------------
- Abre la carpeta `blog/` en el proyecto.
- Elimina el archivo anterior llamado `post.txt` (si existe).
- Crea un nuevo archivo de texto y guárdalo con este nombre exacto: `post.txt`
- Escribe dentro tu publicación (puedes usar emojis, saltos de línea, etc.).
- Sube ese archivo `post.txt` a la carpeta `blog/`.

⚠️ Reglas importantes
---------------------
- El archivo debe llamarse exactamente `post.txt`.
- Otros nombres como `blog.txt`, `entrada1.txt` NO funcionarán.
- Solo debe haber un archivo `.txt` a la vez en la carpeta `blog/`.
- No necesitas tocar el HTML ni el JavaScript.

💡 ¿Qué pasa cuando hago clic en “Blog”?
---------------------------------------
- El visitante hace clic en el botón “Blog” del menú.
- El sistema carga automáticamente el contenido del archivo `post.txt`.
- El contenido se muestra en una ventana centrada, elegante y adaptada para celulares.
